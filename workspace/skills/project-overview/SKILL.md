# Project Overview

Use, wenn Momo einen Überblick oder Status über sein Setup / seine Projekte will:
`references/projects.md` lesen und strukturiert zusammenfassen (Hosts, Services, offene Punkte).

## Workflow

1. `references/projects.md` lesen (lazy geladen — enthält den eigentlichen Projekt-Index).
2. Auf die Frage zugeschnitten zusammenfassen — nicht den ganzen Index dumpen.
3. Offene Baustellen/Gotchas explizit benennen, wenn nach Status gefragt wird.

## Stop-Regel

Fakten, die nicht im Index stehen, nicht erfinden. Bei Unklarheit Momo fragen.
